# B2 Format Notes

## Observed

- The native content directory contains `GearGame.b2index` and files ending in `.b2container`.
- The recorded index is 62,688,696 bytes.
- Bytes `0x00..0x03` are ASCII `TCB2`.
- Bytes `0x04..0x07`, interpreted as a little-endian unsigned 32-bit integer, equal `6`.
- The inventory contains 141 containers totaling 120,453,062,656 bytes.

## Not yet decoded

- Header field semantics after offset `0x07`.
- Record table boundaries and count ownership.
- Container selection, spans, alignment, and precedence.
- Compression method, block framing, dictionaries, checksums, and error recovery.
- Package naming, dependency identity, and reconstructed byte boundaries.

Unknown fields must use offset-based names such as `u64_0x08` until repeated references and range checks prove semantics.
