# Maintained Source

Maintained code will live here after parser behavior is backed by deterministic fixtures and explicit build scope.

Planned modules:

- B2 index and container readers;
- decompression and integrity adapters;
- package reconstruction and dependency resolution;
- mesh, material, texture, skeleton, animation, and scene decoders;
- build-neutral scene IR;
- Blender import and coverage adapters.

The metadata-only B2 inventory tool currently lives in `tools/`. Historical patch fragments remain in `research/`.
