# Research Model

This repository borrows organizational lessons, not source code, from established format-research projects:

- Kaitai Struct format gallery: explicit endianness, offsets, cross-references, and machine-readable grammar.
- ValveResourceFormat: separation between parsing, decompilation, exporting, and known limitations.
- UE Viewer and Unreal-Library: mature Unreal package and asset research.
- CUE4Parse and FModel: build-aware Unreal container, package, and asset investigation.

The project differentiator is a source-proof claim ledger connected directly to Blender reconstruction coverage across every visual scene layer.

The repository should look polished because uncertainty is classified and testable, not because uncertainty is hidden.
