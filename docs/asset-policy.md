# Asset Policy

Do not commit proprietary game data or exports derived from it.

Forbidden repository content includes `.b2container`, `.b2index`, Unreal packages and sidecars, meshes, textures, materials, animation, audio, video, `.blend`, FBX, GLTF, OBJ, and bulk binary dumps.

Allowed evidence includes source-relative identifiers, sizes, hashes, byte offsets, short hex windows needed to identify a format header, aggregate counts, parser diagnostics, and synthetic fixtures that contain no game payload.

Generated extraction output belongs outside Git and should be reproducible from legally obtained local files.
